# cbis-ddsm-breast-cancer-classification-resnet18

Project Overview
This project implements breast cancer classification using a Convolutional Neural Network (CNN) through transfer learning with the pretrained ResNet18 architecture.

Developed using PyTorch, the model is trained and evaluated on the CBIS-DDSM (Curated Breast Imaging Subset of Digital Database for Screening Mammography) dataset to classify breast masses as benign or malignant.

Training leverages NVIDIA GPU acceleration through CUDA to improve computational efficiency and reduce model training time.
